# Security Policy

## Reporting a vulnerability

Please avoid posting exploit details publicly. Report security concerns directly to the repository owner through GitHub so they can be reviewed before disclosure.

This project is a static browser application and does not intentionally collect account credentials, payment information, or server-side secrets. If that changes, this policy should be expanded before deployment.

## Supported version

The current production branch is the supported version. Older preview deployments and historical branches are not maintained as security-supported releases.
