# Brain Part(s)y

A browser-first 3D anatomical jigsaw puzzle: put the brain's parts back together.

**Display name:** Brain Part(s)y  
**Repository:** `brain_party`

## Direction

Bring the existing Allen mouse-brain puzzle into the browser so players can open a link and play without installing a desktop application.

- Allen CCFv3 mouse-brain annotation at 25 µm, with broad-to-detailed region difficulties.
- Ground-plane dragging, optional gravity, and height assistance.
- Anatomically constrained snapping with clear success feedback.
- A completion bar, timer, and shuffle for unconnected pieces.
- A short, skippable opening and an approachable first-play tutorial.
- Load only the selected difficulty and optimize mesh delivery for the web.
- Device-local save and resume for ongoing puzzles.

## Status

Repository initialized for the browser revamp. The existing game source and atlas assets have **not yet been imported**, and no playable website has been deployed from this repository.

The repository is private. Hosting will be configured separately without changing repository visibility.
